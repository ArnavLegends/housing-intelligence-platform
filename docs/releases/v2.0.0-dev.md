# V2 Development Checkpoint

**Status:** In development  
**Branch:** `v2-product-engineering`  
**Date:** 2026-09-19

## Purpose

This checkpoint marks the transition from the documented V1 prototype into V2 product engineering.

V1 remains the stable baseline on `main`. V2 development is isolated on `v2-product-engineering` until the new application experience is implemented, tested, reviewed, and ready for release.

## Completed before this checkpoint

- V1 engineering audit and product documentation.
- V2 product roadmap.
- Shared inference service in `ml/inference.py`.
- Streamlit and FastAPI reuse the same inference implementation.
- Streamlit remains independently deployable on Streamlit Cloud.

## V2 product direction

The project is evolving from a housing-price prediction dashboard into a residential property intelligence product.

The primary V2 workflow is:

```text
Home
  ↓
Sell Property
  ↓
Property Valuation
```

The product should expose useful decisions and explanations rather than presenting the underlying ML schema as the primary user experience.

## Phase 1 scope

Phase 1 is the Product/UI Foundation:

- redesigned landing experience
- product-oriented navigation
- Sell Property as the primary working journey
- Buy Property as a non-functional future workflow
- Invest as a non-functional future workflow
- Explore Market as a non-functional/future workflow
- improved visual hierarchy
- cleaner terminology
- reduced sidebar complexity
- preservation of existing prediction and analytics behavior

## Out of scope for this checkpoint

- model retraining or algorithm changes
- dataset replacement
- remote FastAPI deployment
- valuation uncertainty methodology
- buyer/investor functionality
- LLM/chatbot integration
- databases or authentication
- unrelated infrastructure changes

## Verification standard

The Phase 1 implementation is not complete until the changed application is tested, reviewed for regressions, documented, and committed as its own milestone.
